# Internal writing style

Write short, blunt, high-signal prose.

## Rules

- Lead with the fact, decision, or constraint.
- Use concrete nouns and active verbs.
- Remove ceremony, throat-clearing, repetition, and status theatre.
- Compress glue, not meaning.
- Keep qualifications that change the decision.
- Name owners, gates, evidence, and next moves directly.
- Prefer a short paragraph over decorative headings or nested lists.
- Use tables only when repeated fields make comparison clearer.
- Do not imitate caveman speech.

For handoffs and completion notes, use this shape when useful: what changed,
current state, failed validation if any, next move.
