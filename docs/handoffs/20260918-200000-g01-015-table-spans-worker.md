## What This Thread Was Doing

The table editor landed in g01.009 with rows, columns, headers, alignment, per-edge borders, a keyboard
model and a destructive-action confirmation. It deliberately excluded merging and splitting cells.

This lane adds them: `colspan` and `rowspan`, which the renderer already honours.

## Why It Matters

The renderer supports spans today and a hand-written table can use them, so the editor is the only gap.
It was split out because merge and split is the most destructive thing a grid can do and the hardest to
reverse — this package has no editor history — and the grid needed to exist and work before spans were
designed against it.

## Important Context

- **Merge semantics.** A rectangular selection merges into the top-left cell: that cell takes the
  selection's row and column extent, and the covered cells are removed. Split restores the extent and
  inserts empty cells for the ones covered.
- **Confirm before destroying.** Merging a selection that holds content asks first, in-page and not with
  a browser dialog, exactly as row and column removal already does. There is no undo, and this lane does
  not add one.
- **No ragged tables.** After any merge or split, every row's cells must still add up to the table's
  column count. Repair the shape rather than writing a table the renderer has to guess at. A selection
  that cannot produce a well-formed table is refused rather than written.
- **Keyboard parity.** Merge and split must be reachable without a pointer, and selection must be
  extendable from the keyboard. This is an acceptance item, not a follow-up: contract 004 makes the
  interaction itself the oracle.
- **Sections round-trip.** The editor does not author `section`, and it must keep preserving whatever it
  finds. Merge and split must not disturb a row's section value.
- **Open tensions:** none.

### Interaction oracle

Per contract 004, none of this is demonstrated in a running surface — it is asserted:

- **Keyboard reach** for merge and split, and for extending a selection.
- **Shape after every operation:** a test runs for each merge and split and asserts the rows still sum to
  the column count.
- **Round-trip:** `colspan` and `rowspan` survive save and reload.
- **Content protection:** a content-bearing rectangle triggers the confirmation, and the cells survive.
- **Section preservation:** a fixture row with a section value round-trips unchanged through a merge.
